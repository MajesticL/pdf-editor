# 📄PDF-Editor (Experimental)

A small experimental project where I started exploring how to build a simple in‑browser PDF editor using JavaScript. This was one of those late‑night “I wonder if I can make this work…” ideas, so expect bugs, rough edges, and plenty of room for improvement.

## ✨ Features (Current)

- Upload a PDF file
- Display pages in the browser
- Basic UI structure for editing tools
- Early experiments with canvas rendering and interactions
- Download/export functionality

⚠️ Note: This project is still in a very early, buggy state.
I’m actively debugging and refining the core functionality.

## 🛠️ Tech Stack

- JavaScript: core logic and PDF rendering
- HTML: structure
- CSS: layout and styling
- PDF.js: more reliable PDF rendering

## 🚧 Known Issues

- Rendering inconsistencies
- Tools not fully implemented
- Occasional console errors
- UI layout still in progress

## 📌 Roadmap

- Add text editing tools
- Add drawing/annotation tools
- Improve PDF rendering stability
- Clean up UI and improve usability

### 🤝 About This Project

This is a personal learning project where I experiment with PDF manipulation in the browser. It’s not intended for production use (yet), but it’s a fun sandbox for exploring more advanced JavaScript features
